# BellenneFolio — Ozon Seller API feasibility

Проверено: 22.09.2026.

Этот документ фиксирует только подтверждённый публичный контракт. Доступность каждого метода для конкретного кабинета устанавливается кнопкой «Проверить доступ» и фактической работой тестового чата. Валидный API-ключ не означает наличие прав на чаты или вложения.

## Матрица методов

| Требование Folio | Подтверждённый метод | Состояние реализации | Ограничение |
|---|---|---|---|
| Проверка кабинета | `POST /v1/seller/info` | `OzonAdapter.seller_info` | Проверяет ключ и кабинет, но не права чатов |
| FBS-заказы | `POST /v4/posting/fbs/list` | постраничный импорт с checkpoint | `/v3/posting/fbs/list` отключён 31.08.2026 |
| Список чатов | `POST /v3/chat/list` | cursor pagination | `/v2/chat/list` удалён из документации |
| История чата | `POST /v3/chat/history` | постраничное чтение и dedup по `message_id` | Реальный доступ зависит от кабинета |
| Текст покупателю | `POST /v1/chat/send/message` | outbox, состояния `pending/sent/failed/unknown`, внутренний лимит 1000 символов | Проверяется только явной реальной отправкой в выбранный чат |
| Начать чат | `POST /v1/chat/start` | отдельная write-job без слепого retry | Допустимость зависит от схемы и статуса заказа |
| Файл покупателю | `POST /v1/chat/send/file` | не активирован | Нужны подтверждённые требования и тестовый контекст |
| Входящие вложения | данные `/v3/chat/history` | защищённое скачивание только с доменов Ozon, без redirect, с проверкой DNS и размера | Capability считается подтверждённой после успешного фактического получения |
| Push заказов/чатов | notification API и типы событий Ozon | не активирован; используется polling | Настройка webhook и доступные типы должны быть проверены на кабинете |

## Безопасный режим

Folio не включает автоматизацию, пока одновременно не подтверждены кабинет, заказы, список и история чатов, реальная отправка текста и получение вложения. Проверка подключения ничего не отправляет покупателю. Сетевой сбой write-запроса переводит отправку в `unknown`; автоматического повтора нет до сверки истории.

## Неподтверждённые решения

- FBO/FBS/rFBS кабинета и разрешённые статусы начала диалога.
- Возможность инициировать чат для нужных заказов.
- Реальный формат фотографий в истории конкретного кабинета и срок жизни URL.
- Разрешение на отправку файлов покупателю.
- Поддерживаемые push-типы и политика регистрации webhook.

До проверки кабинета эти пункты остаются блокерами только для production-автоматизации, но не для настройки, product mapping, редактора сценариев, dry-run и ручной работы с уже синхронизированными чатами.
