# Parity: API внешнего приложения, версия 1

Базовый адрес: `https://one.customcraft-mes.ru/parity/api/v1`.
Работает без расширения, cookies, CSRF и сессии браузера. HTTPS обязателен на публичном адресе.
Обновить необходимо Parity **и gateway**: только два указанных маршрута пропускаются gateway без браузерной авторизации; Bearer проверяет Parity.

## Токен

В Parity → Интеграции → API внешнего приложения сохраните случайный секрет длиной 32–256 ASCII-символов без пробелов (рекомендуется 32 случайных байта в hex).
Тот же секрет используется во внешнем приложении. В БД хранится SHA-256, исходный токен не возвращается в UI и не журналируется. Замена/отзыв немедленно отключает старый токен.
Один токен даёт чтение каталога и запись цен **только владельца**, не доступ к чужим товарам или настройкам. Не передавайте owner_id, заголовки X-Bellenne-* и ключи маркетплейсов.

Заголовки обоих запросов:

```http
Authorization: Bearer <TOKEN>
Accept: application/json
```

## 1. Получить каталог

Тот же JSON для POST prices можно вставить текстом через **Parity → Интеграции → Импорт цен из JSON**.
Вставьте JSON до 64 KiB в кодировке UTF-8, с полями version/event_id/prices из раздела 2. Выбор файла не требуется.
Токен при импорте через кабинет не требуется: используются текущая сессия и CSRF.
Все проверки, атомарность, смена контекста и идемпотентность общие с API, включая повтор одного события через разные способы доставки.
После импорта открывается страница задания; при повторе — исходного задания. Технический UI-маршрут: `POST /parity/prices/import`, поля формы `csrf_token` и `json_text`.

```http
GET /parity/api/v1/products?marketplace=ozon&limit=100&after_id=0
```

Параметры: `marketplace` — необязательный `wb` или `ozon`; без него обе площадки.
`limit` — 1–500, по умолчанию 100. `after_id` — ID Parity, по умолчанию 0.
Возвращаются существующие активные товары импортированного каталога, по возрастанию ID.

```json
{
  "items": [{
    "id": 123,
    "marketplace": "ozon",
    "sku": "3267204518",
    "offer_id": "ART-40x60",
    "name": "Картина 40×60",
    "external_id": "3244447271"
  }],
  "next_after_id": 123
}
```

Для следующей страницы передавайте `next_after_id` как `after_id`, сохраняя фильтр. `null` означает конец (в том числе пустой каталог). Это курсор, не номер страницы; каталог может изменяться между запросами.
`sku` — покупательский SKU Ozon / nmID WB, строка, может быть null у неполного каталога. Такой товар сначала нужно дополнить импортом каталога, не угадывать SKU.
`offer_id` — артикул продавца. `external_id` — product ID Ozon / nmID WB. `id` — внутренний ID Parity. Эти идентификаторы не взаимозаменяемы.

## 2. Передать цены

```http
POST /parity/api/v1/prices
Content-Type: application/json
```

```json
{
  "version": 1,
  "event_id": "8113a9a0-9a25-4ac0-a98c-a885620fc935",
  "prices": [{
    "marketplace": "ozon",
    "sku": "3267204518",
    "observed_at": "2026-10-22T15:30:00+03:00",
    "currency": "RUB",
    "loyalty_price": "2917.00",
    "discount_price": "3043.00",
    "base_price": "5000.00"
  }]
}
```

Время примера замените реальным временем чтения цены. `observed_at` обязательно с часовым поясом; не более 5 минут в будущем и не старше порога stale_hours кабинета (по умолчанию 24 часа).
Размер тела ≤64 KiB; 1–100 записей. Пакет атомарен: ошибка одной записи отменяет весь новый пакет. Лишние поля запрещены.
`version`, `event_id` (UUID), `prices`, а в записи `marketplace`, `sku`, `observed_at`, `loyalty_price` обязательны. `currency` по умолчанию RUB, другие валюты не поддерживаются.
Деньги — **строки** с положительным десятичным числом, до двух знаков после точки и максимум 999999999999.99; не JSON float, не текст с символом рубля. Неизвестная цена — null, не ноль.

Значения соответствуют витринным ценам:

- `loyalty_price`: WB Кошелёк / Ozon Карта — основная сравниваемая цена. Не подставляйте сюда обычную или клубную цену.
- `discount_price`: обычная текущая цена покупки; необязательно, по умолчанию null.
- `base_price`: зачёркнутая справочная цена; необязательно, по умолчанию null.

Внешнее приложение отвечает за достоверность и стабильность своего покупательского контекста. Parity не проверяет сайт повторно. Цены сохраняются в существующую историю с `collector=external_api`; сравнения обновляются сразу.
Товар ищется строго по владельцу токена + marketplace + sku. Не создаётся автоматически по артикулу; SKU должен однозначно существовать в каталоге. Один товар нельзя повторять в пакете.
Наблюдение должно быть строго новее текущего снимка товара. Старые наблюдения не перезаписывают текущие цены.

При первом импорте после браузера/серверного сбора меняется версия контекста, выключается серверное расписание. Старые снимки сохраняются, но не сравниваются с новым контекстом до обновления обеих площадок. Последующие пакеты внешнего API используют тот же контекст. Запуск браузерного/серверного сбора снова меняет контекст. Во время активного задания новый пакет отклоняется с 409: завершите или остановите его в UI.

Успех HTTP 200:

```json
{"accepted": true, "duplicate": false, "job_id": 456}
```

`job_id` — завершённое задание импорта в существующем журнале, не задание расширения. Фоновый worker для приёма пакета не требуется.
После таймаута повторяйте **тот же event_id и тот же пакет**, включая время. Повтор возвращает HTTP 200 с `duplicate: true` и исходным job_id, не создаёт снимки повторно. Идемпотентность сохраняется после перезапуска и замены токена владельца.
Тот же event_id с другим содержимым → 409. Для нового наблюдения нужен новый UUID.

## Ошибки

- 401 — отсутствует/неверен/отозван Bearer.
- 404 — SKU не найден у владельца.
- 409 — активное задание; неоднозначный/повторный SKU; устаревшая относительно текущей цена; конфликт event_id. Причина в `detail`.
- 413 — тело превышает 64 KiB.
- 422 — неверный формат/поля/цены/время.
- Сеть/5xx — повторить тот же пакет и UUID с задержкой; не создавать новое событие для обхода неопределённого результата.

Пример чтения каталога:

```bash
curl 'https://one.customcraft-mes.ru/parity/api/v1/products?marketplace=wb&limit=100' \
  -H "Authorization: Bearer $PARITY_TOKEN" -H 'Accept: application/json'
```

Пример отправки сохранённого JSON:

```bash
curl 'https://one.customcraft-mes.ru/parity/api/v1/prices' \
  -H "Authorization: Bearer $PARITY_TOKEN" -H 'Content-Type: application/json' \
  -H 'Accept: application/json' --data-binary @prices.json
```
