# WB Ads Statistics

Локальное веб-приложение для ежедневного сбора статистики рекламных кампаний
Wildberries, хранения всей истории в SQLite и выгрузки формульного Excel-отчёта.

## Что реализовано

- регистрация и авторизация по логину и паролю;
- изоляция кабинета, истории, расписания и выгрузок по пользователям;
- scrypt-хэширование паролей и подписанные HTTP-only сессии;
- добавление и обновление API-ключа кабинета;
- шифрование токена перед записью в SQLite;
- проверка подключения и доступных кампаний;
- ежедневный шедулер с часовым поясом и повторной загрузкой последних дней;
- ручной запуск за произвольный период;
- идемпотентная запись по дате, кампании и артикулу;
- полноценный веб-отчёт с фильтрами периода, групп и категорий WB;
- KPI из Excel, динамика, рекламная воронка, цветовые целевые зоны,
  топы артикулов и кампаний;
- просмотр всей истории с фильтрами;
- ручная корректировка групп товаров для структуры Excel;
- выгрузка отдельного формульного свода `Итого по группам`,
  детализации `По артикулам` и листа
  `Целевые показатели по РК`;
- скрытый лист исходных значений API, из которого все KPI и итоги считаются
  формулами Excel.

Используются актуальные методы WB Продвижения:

- `GET /adv/v1/promotion/count` — список кампаний;
- `GET /api/advert/v2/adverts` — названия, товары и предметы;
- `GET /adv/v3/fullstats` — статистика.

Официальная документация:
https://dev.wildberries.ru/openapi/promotion

## Запуск в Docker

```bash
cp .env.example .env
docker compose up -d --build
```

Откройте:

```text
http://IP_СЕРВЕРА:43817/register
```

Порт `43817` намеренно нестандартный. По умолчанию Docker публикует его на всех
интерфейсах (`0.0.0.0`). Адрес и порт настраиваются в `.env`:

```dotenv
APP_BIND_HOST=0.0.0.0
APP_PORT=43817
```

Проверка на Linux-сервере:

```bash
docker compose ps
curl http://127.0.0.1:43817/healthz
ss -lntp | grep 43817
```

В `docker compose ps` должен отображаться проброс
`0.0.0.0:43817->8000/tcp`. Если локальный `curl` работает, но соединение по IP
не устанавливается, откройте TCP-порт в firewall сервера и в сетевых правилах
хостинга. Например, для активного UFW:

```bash
sudo ufw allow 43817/tcp
sudo ufw status
```

Для публичного сервера рекомендуется закрыть прямой доступ к порту, поставить
перед приложением HTTPS reverse proxy (Nginx, Caddy или Traefik), установить
`APP_BIND_HOST=127.0.0.1` и `SESSION_HTTPS_ONLY=true`. Без HTTPS логин, пароль и
API-ключ передаются по сети без транспортного шифрования.

Остановка:

```bash
docker compose down
```

SQLite, токен и ключ шифрования сохраняются в именованном Docker volume
`wb_ads_data`. Команда `docker compose down -v` удалит этот volume и все данные,
поэтому для обычной остановки `-v` не используйте.

## Первый запуск

1. Создайте пользователя на странице **Регистрация**.
2. В разделе **Кабинет** вставьте токен с категорией **Продвижение**.
3. Нажмите **Проверить подключение**.
4. В разделе **Автосбор** укажите время и включите расписание.
5. Для первичного заполнения вручную задайте нужный исторический период.
6. На странице **Все данные** при необходимости уточните группы товаров.
7. Скачайте Excel за весь период или с выбранными датами.

При обновлении существующей установки первый зарегистрированный пользователь
автоматически получает ранее настроенный кабинет и всю накопленную историю.
Следующие пользователи создают собственные изолированные кабинеты.

WB ограничивает один запрос статистики периодом 31 день и 50 кампаниями.
Приложение автоматически разбивает большой диапазон и выдерживает
официальный интервал 20 секунд между запросами.

## Формулы Excel

Исходными значениями являются показы, клики, затраты, добавления в корзину,
заказы, сумма заказов и отмены. На видимом листе формулами рассчитываются:

- CPM = затраты / показы × 1000;
- CTR = клики / показы;
- CPC = затраты / клики;
- конверсия в корзину = корзины / клики;
- конверсия в заказ = заказы / корзины;
- CPO = затраты / заказы;
- ДРРЗ = затраты / сумма заказов;
- дневные и периодные итоги по группам и артикулам.

Книга помечена для полного автоматического пересчёта при открытии в Excel.

## Локальная разработка

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 43817
```

Для тестов используется имитация актуальных ответов WB API: реальный токен не
нужен.
