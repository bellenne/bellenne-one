Пользователь из MES

Токен определяет аккаунт BellenneOne, а заголовок запроса — сотрудника, запустившего расчёт в MES.

Обязательный заголовок
X-MES-User
Значение
Логин или отображаемое имя пользователя из авторизации MES
Совместимый alias
X-Bellenne-Username

Передавать ID аккаунта BellenneOne больше не нужно: владелец, настройки и доступная ему история определяются по персональному токену. В журнале сохраняется именно значение X-MES-User.

Пример запроса

MES передаёт персональный токен аккаунта и пользователя, инициировавшего расчёт.

curl -X POST "https://your-host/nest/api/v1/calculate" \
  -H "Content-Type: application/json" \
  -H "AUTH-TOKEN: <API_TOKEN_ИЗ_NEST>" \
  -H "X-MES-User: ivan.petrov" \
  -d '{"items":[{"article":"ONE_100x270","width_cm":100,"height_cm":270,"quantity":17}]}'
